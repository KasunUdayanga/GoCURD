# Go Book API

This is a simple Go application that implements a REST API for managing books. The API supports the following operations:

- **Search books** based on title and description.
- **CRUD operations** for books (Create, Read, Update, Delete).
- Optimized search using **Goroutines** and **Channels** to parallelize the search process.

## Requirements

- [Go 1.18 or higher](https://golang.org/dl/) (Go programming language)
- A code editor (e.g., [Visual Studio Code](https://code.visualstudio.com/))
- [Postman](https://www.postman.com/downloads/) for testing the API (optional but recommended)
